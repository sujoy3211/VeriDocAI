# VeriDoc AI

Explainable AI system for detecting forged or manipulated documents.

## Features
- Upload PDF/Image
- Detect suspicious tampering signs
- Risk Score: Low / Medium / High
- Confidence %
- Explainable reasons
- Downloadable report
- Supports regional language use-cases

## Tech Stack
- Frontend: HTML/CSS/JavaScript
- Backend: FastAPI
- AI Tools: OpenCV, OCR Logic
- Documentation: ThinkRoot

## Problem Solved
Fake marksheets, forged certificates, scholarship fraud, manual verification delays.
